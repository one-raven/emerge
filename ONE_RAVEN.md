# One Raven patches

This branch (`one-raven/hub-patches`) is [Emerge](https://hex.pm/packages/emerge) 0.5.1 (Apache-2.0) with
performance patches for One Raven's home server (RK3566: four Cortex-A55 cores, Mali-G52 on Panfrost,
1200 × 1920 DSI panel at 54 Hz). It starts at upstream `644e921`, the last upstream commit whose `lib/` and
`native/` match the Hex 0.5.1 package. Every change is marked `One Raven patch` in the source; the whole diff
is `git diff 644e921..one-raven/hub-patches`.

The hub app depends on this branch by git ref (`apps/hub/mix.exs`, `emerge_opts/0`); set `EMERGE_PATH` to a
local checkout to build against it instead. `checksum-Elixir.EmergeSkia.Native.exs` comes from the Hex 0.5.1
package so host builds can still download the stock precompiled NIF; Nerves target builds always compile
this source (patch 7).

The patches are written to be offered upstream one at a time. Each stands on
its own except where noted.

**Scroll physics** (`events/runtime/physics.rs`). A press becomes a drag
after `touch_slop` px; the content then follows the finger. The release
velocity (by default a one-pole filter, alpha 0.25, over moves at least
4 ms apart; with `velocity_window_ms` a least-squares fit over that window)
is clamped to `max_velocity`; below `min_velocity` nothing happens. A fling
follows Android's `OverScroller` spline (Flutter's
`ClampingScrollSimulation`): duration = 2.358 × 0.35 × (v / v_ref)^(1/1.358) s
with v_ref = friction × 51890 / 0.35 (2224 px/s at 0.015), distance =
v × duration / 2.358, eased as 1 − (1 − t)^2.358. 1000 / 3000 / 6000 px/s
travel 194 / 1309 / 4361 px in 0.46 / 1.03 / 1.71 s. iOS's
`UIScrollView` (`decelerationRate` 0.998 per ms, exponential) travels
v / 2 ≈ 499 / 1497 / 2994 px and keeps creeping for 2–3 s, so short flings go
further on iOS and hard ones further here. `overscroll: :bounce` adds iOS's
rubber band (`(1 − 1/(x × 0.55 / d + 1)) × d`, d the viewport) and a
critically damped spring back (ω = 12/s); the default clamps at the edges.
